## customer-churn-analysis-and-prediction
Customer churn analysis and prediction using Machine Learning, SQL, Python, and Power BI dashboard visualization.

## Overview
This project focuses on customer churn analysis and prediction using Machine Learning and Power BI. The project helps identify customers who are likely to churn and provides business insights through interactive dashboards.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SQL
- Power BI
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
- Data collection using SQL
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Machine Learning model building
- Customer churn prediction
- Power BI dashboard visualization

## Machine Learning Model
- XGBoost Classifier

## Model Performance
The XGBoost Classifier achieved an accuracy of 84% for customer churn prediction.

## Dashboard Features
- Customer churn summary
- Churn prediction analysis
- Customer risk analysis
- State-wise churn analysis
- Service-based churn analysis
- Interactive Power BI dashboard

## Key Insights
- Identified major reasons behind customer churn
- Analyzed churn patterns across different customer groups
- Predicted customers at high risk of churn
- Generated business insights using visual dashboards
